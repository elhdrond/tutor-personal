# Tutor Personal de Programación

Repositorio de instrucciones para mi tutor personal de programación en Claude Code.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| `tutor-personal.md` | Instrucciones del tutor: metodología, ficha de estudiante y reglas de enseñanza |
| `CLAUDE.md` | Instrucciones para Claude Code: cómo activar el modo tutor |

## Uso

Conecta este repositorio en una sesión de Claude Code junto con el repositorio del curso que quieras trabajar. Luego escribe:

> "Tutor, vamos a trabajar con [tema o archivo del curso]"

Claude leerá las instrucciones de este repo y el material del curso para actuar como tu tutor socrático.

## Personalización

Rellena la sección **"Sobre mí — Ficha de estudiante"** en `tutor-personal.md` con tu nivel, objetivos y puntos débiles para que el tutor se adapte a ti.
